# Struggle of Students (SS)

**A platform built by students, for students.** 
SS connects students to internships, jobs, events, mentors, and a community that actually shows up. Our goal is to ensure no student has to struggle alone by turning struggles into opportunities.

## About the Startup
Struggle of Students (SS) provides a wide variety of support and opportunities for the student community:
* **Career & Internships:** Resume reviews, mock interviews, placement drives, and direct job/internship referrals.
* **Student Problems & Guidance:** Confidential one-on-one conversations for academic, career, and personal support from seniors.
* **SS Events & Volunteering:** Organizing fests, workshops, and hackathons with opportunities for hands-on volunteer experience.
* **SS IT Solutions:** Web and app development by student talent, giving them real-world project experience.
* **SS Band & Talent Showcase:** Live performances for college fests and an open stage for student musicians and artists.
* **Leadership Roles:** Campus Ambassador programs and core team roles to build leadership skills.

## About the Website
This repository contains the landing page for the SS community, designed to be youthful, clean, and highly interactive.
* **Tech Stack:** Vanilla HTML, CSS, and JavaScript (Zero dependencies, incredibly fast).
* **Styling:** Custom CSS with a minimal off-white/ink palette, indigo primary, and lime highlights. Fully responsive and mobile-friendly.

### Content Management (No Code Required)
The SS team can update the website's content without needing to understand HTML or CSS. 
All site content is driven by a single file: `js/data.js`. 
By simply modifying the values in `js/data.js`, you can:
* Update important links (Google Forms, WhatsApp, social media).
* Post new updates to the scrolling ticker.
* Schedule upcoming Events and control volunteer slot capacity (automatically displays "Slots Full").
* Schedule Online Sessions (Zoom/Meet) and automatically unlock meeting links shortly before the session starts.
* Update Student Placement numbers and success stories.
* Manage Team and Leadership profiles.
